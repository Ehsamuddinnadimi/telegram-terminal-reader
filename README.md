# Telegram Terminal Reader

A Python-based tool that allows you to read Telegram messages directly in your terminal, save sessions, and retrieve verification codes securely.

## 🚀 Features
- **Real-time Message Display:** View incoming Telegram messages directly in your terminal.
- **Session Management:** Save your login session securely so you don't need to log in every time.
- **Verification Code Retrieval:** Fetch login verification codes automatically.
- **Message History:** Store messages locally for future reference.

## 🛠️ Technologies Used
- Python 3.x
- Telethon (Telegram API)
- Asyncio
- Environment Variables (for secure credential storage)
